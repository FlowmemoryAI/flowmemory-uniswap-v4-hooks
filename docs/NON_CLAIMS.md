# Non-Claims

FlowMemory's Base Sepolia production path does not claim:

- Base mainnet deployment;
- custody;
- escrow;
- wallet authorization;
- fund protection;
- semantic truth;
- model correctness;
- GPU hardware acceleration;
- production verifier network readiness;
- audited production infrastructure;
- x402 settlement unless a real payment receipt is supplied;
- on-chain bond escrow unless a real escrow contract and release record exist.

Safe language:

```text
Base Sepolia production-like path.
Observed testnet release evidence when release packets validate.
PulseWatch attaches receipt metadata after hook execution.
```

Unsafe language:

```text
Base mainnet live.
FlowMemory protects funds.
The hook knows txHash during execution.
Production verifier network ready.
```
