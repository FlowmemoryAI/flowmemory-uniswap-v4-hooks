# AxiomWrit

AxiomWrit is the R&D primitive that pushes FlowMemory beyond memory storage.

It is proof-conditioned cognition for machine agents.

## Core Idea

An AI agent should not treat every memory as equally admissible.

Some memories are:

- receipt-bound;
- reader-attached;
- rooted in a FlowPulse;
- scoped to a rootfield;
- safe to cite;
- unsafe to overclaim;
- not enough to justify action.

AxiomWrit turns that difference into a deterministic object.

## Stack

```text
Uniswap v4 afterSwap boundary
  -> FlowPulse
  -> receipt-aware reader
  -> AxiomWrit
  -> belief / citation / reuse / action gate
  -> AgentPulse / ModelPulse / ComputePulse
```

## Why This Needs FlowPulse

The chain boundary matters because the root fact is externally settled.

The hook emits the memory signal. The reader attaches the proof envelope. AxiomWrit converts that proof envelope into a scoped cognitive permission.

That is different from a vector database.

Vector search finds similar context.

AxiomWrit decides what a machine is allowed to believe about a proof-backed artifact.
