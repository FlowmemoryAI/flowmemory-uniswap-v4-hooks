# Obligation Membrane Example

Run:

```bash
python tools/obligation_membrane.py demo --pretty
```

Obligation Membrane checks whether delegated agent-commerce obligations
preserve memory, compute, payee, refusal, aggregation, rootfield, and closure
constraints end to end.

It is not custody, escrow, wallet authorization, fund protection, work-quality
proof, semantic truth, model correctness, GPU acceleration, live mainnet
evidence, or production verifier infrastructure.
