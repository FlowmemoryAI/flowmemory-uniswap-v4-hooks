# Compute ChargeLine Example

Run:

```bash
python tools/compute_chargeline.py demo --pretty
```

Compute ChargeLine checks whether a compute payment matches the
memory-consistent compute route: fresh compute, safe reuse, unsafe reuse,
runtime commitment, attestation reference, payment requirement, and buyer
memory head.

It is not custody, escrow, wallet authorization, fund protection, work-quality
proof, semantic truth, model correctness, GPU acceleration, hardware execution
proof, live mainnet evidence, or production attestation infrastructure.
