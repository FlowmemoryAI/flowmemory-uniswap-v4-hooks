# FlowMemory Reality Check Screenshot Guide

Run:

```bash
python tools/launch_reality_check.py --pretty
```

Capture the terminal from the title through the final result:

```text
FlowMemory Reality Check
...
Result: FlowMemory can tell impossible histories from live ones using receipt-bound FlowPulse boundaries.
```

The screenshot should show:

- the boundary model;
- the hook invariant surface;
- the FlowLitmus case table;
- `8/8 passed`;
- the final result line.

Use this caption:

```text
FlowMemory Reality Check: live histories pass, impossible histories fault.
```

Do not caption it as a mainnet deployment, audit, custody system, fund
protection system, semantic verifier, or GPU accelerator.
