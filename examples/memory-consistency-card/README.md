# Memory Consistency Card Example

This folder contains the screenshot-ready output for:

```bash
python tools/memory_consistency_card.py --pretty
```

The card is the compact launch artifact for FMM-0, the FlowMemory Agent Memory
Model:

```text
Everyone treated agent memory like retrieval. FlowMemory treats it like a memory model.
```

`FM-C0` through `FM-C5` are local repo evidence. `FM-C6` stays pending until the
Base Sepolia release record includes public receipt evidence.
